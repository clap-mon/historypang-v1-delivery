## 1. 프로젝트 개요

- **소프트웨어 명칭**: 역사팡: 선사시대와 고조선 (History-Pang v1)
- **개발 대상**: 초등학교 5학년 학생 및 역사 기초 학습자
- **장르**: 스토리텔링 기반 역사 개념 탐구 + 턴 기반 덱빌딩 카드 배틀 (RPG 에듀테인먼트)
- **개발 환경**: Next.js 16 (Turbopack), React 19, TypeScript, Web Audio API, Vanilla CSS
- **핵심 스토리**:
  - 알 수 없는 시공간의 틈에 휘말려 선사시대로 시간 여행을 떠나게 된 주인공!
  - 별빛 안내자 **'역사별이'**와 함께 구석기, 신석기, 청동기, 고조선의 유물과 지혜를 모으고,
  - 현대로 통하는 시간의 문을 막아서는 3대 고대 수호령(**원시 암석수호령 ➔ 거석의 지배자 ➔ 고조선의 수호군주**)과의 전략 카드 대결에서 승리하여 무사히 현대의 집으로 귀환하는 모험기입니다.

## 2. 교육과정 연계 기준 및 학습 목표

본 소프트웨어는 **2022 개정 교육과정** 및 **2015 개정 교육과정 초등 5학년 2학기 사회 1단원 (옛사람들의 삶과 문화)**의 성취기준을 100% 준수하여 제작되었습니다.

### 🎯 단원별 핵심 성취기준
- **[5사01-01]** 선사 시대 사람들의 생활 모습을 유물과 유적을 통해 살펴보고, 오늘날의 생활 모습과 비교한다.
- **[5사01-02]** 고조선의 건국 과정과 주요 사회 모습을 살펴보고, 우리 역사 최초의 국가로서 갖는 의의를 파악한다.

### 📚 스테이지별 상세 학습 내용
| 스테이지 | 시대 구분 | 핵심 유물 및 유적 | 주요 학습 개념 및 생활 모습 |
| :---: | :---: | :--- | :--- |
| **1단계** | **구석기 시대** | 주먹도끼, 긁개, 슴베찌르개 | 뗀석기 제작 기법, 사냥과 채집, 불의 발견, 동굴·막집 이동생활 |
| **2단계** | **신석기 시대** | 빗살무늬 토기, 가락바퀴, 뼈바늘, 돌도끼, 갈판과 갈돌 | 간석기, 농경과 목축의 시작(신석기 혁명), 강가·바닷가 정착 및 움집 생활, 원시 수공업(옷·그물 제작) |
| **3단계** | **청동기 시대** | 비파형 동검, 거친무늬 거울, 거푸집, 반달 돌칼, 탁자식 고인돌 | 청동 무기·제사 도구, 농기구는 여전히 석기(반달 돌칼로 벼 이삭 수확), 잉여 생산물과 사유재산, 빈부격차 및 지배 계급(족장) 출현 |
| **4단계** | **고조선 건국** | 탁자식 고인돌, 비파형 동검, 미송리식 토기 문화권 지도 | 단군왕검 건국 이야기(삼국유사 고조선조 기록, 환웅과 웅녀, 홍익인간 정신), 제정일치 사회, 8조법(생명 존중, 농경 사회, 사유재산 인정, 화폐 사용, 노비 계급) |
| **5단계** | **3단계 보스 총력전** | 1~4단계 전 시대 유물 종합 | 선사시대부터 고조선까지 배운 전 범위 역사 퀴즈를 풀고 행동력을 얻어 고대 수호령 3연전을 돌파하는 최종 시험대 |

## 3. 주요 게임 시스템 및 기능

1. **4대 시대 인터랙티브 탐구 보드**:
   - 구석기·신석기·청동기·고조선의 핵심 유물과 주거 생활 모습을 시각 자료로 탐구하고, 시대별 확인문제를 풀어 개념을 확립합니다.
2. **턴 기반 전략 카드 배틀**:
   - 역사 퀴즈를 풀어 행동력(Energy)을 얻고, 상황에 맞게 카드를 조합하여 3대 고대 수호령을 차례로 제압하는 전략 전투입니다.
3. **4대 고유 유물 퀵슬롯**:
   - 시대를 클리어할 때마다 획득하는 고유 유물 4종(역사 나침반, 승리의 불씨, 청동 방울, 진실의 청동거울)을 퀵슬롯이나 단축키(`Q, W, E, R`)로 즉시 발동하여 전투를 유리하게 이끌 수 있습니다.
4. **12대 역사 도전 칭호 도감**:
   - 시대 탐구 완주, 보스 격파, 고득점 달성 등 학습 성취도에 따라 총 12종의 역사 도전 칭호를 도감에 영구 수집할 수 있습니다.

### 1) 문화유산 유물 및 유적 실사 자료 (국립중앙박물관 및 국가유산청)
- **제공 기관**: **국립중앙박물관(National Museum of Korea)**, **국가유산청(Korea Heritage Service)**
- **적용 라이선스**: **공공누리 제1유형 (KOGL Type 1)**
- **수록 유물 및 유적 실사 목록 (총 15종)**:
  1. `handaxe.webp`: 주먹도끼 (연천 전곡리 유적 출토 뗀석기)
  2. `scraper.webp`: 긁개 (가죽 손질 및 조리용 뗀석기)
  3. `tanged_point.webp`: 슴베찌르개 (이음 도구로 활용된 후기 구석기 뗀석기)
  4. `comb_pottery.webp`: 빗살무늬 토기 (서울 암사동 유적 출토 신석기 토기)
  5. `spindle_whorl.webp`: 가락바퀴 (신석기 실 잣기 도구)
  6. `bone_needle.webp`: 뼈바늘 (신석기 옷 제작 도구)
  7. `ground_stone_axe.webp`: 돌도끼 (신석기 간석기)
  8. `ground_arrowhead.webp`: 돌화살촉 (신석기 사냥용 간석기)
  9. `saddle_quern.webp`: 갈판과 갈돌 (신석기 곡물 가공 도구)
  10. `mandolin_dagger.webp`: 비파형 동검 (청동기 대표 무기)
  11. `coarse_pattern_mirror.webp`: 거친무늬 거울 (청동기 제사용 도구)
  12. `bronze_mold.webp`: 청동기 거푸집 (청동 제품 제작 틀)
  13. `semilunar_knife.webp`: 반달 돌칼 (청동기 곡식 이삭 수확 석기)
  14. `table_dolmen.webp`: 탁자식 고인돌 (강화 지석묘 등 북방식 고인돌)
  15. `cave.webp`: 단양 금굴 유적 (국가유산청 충북기념물 제102호, 대표적인 구석기 자연 동굴 유적 실사)

## 6. 기술 스택 및 시스템 사양

### 💻 기술 스택
- **Framework**: [Next.js](https://nextjs.org/) 16.3.2 (App Router & Turbopack)
- **Library**: React 19, TypeScript 5
- **Style**: Pure Vanilla CSS Modules (CSS3 Custom Properties, Responsive Grid & Flexbox)
- **Audio Engine**: Web Audio API (외부 무거운 오디오 파일 의존 없이 웹 표준 신디사이저로 타격음·효과음 렌더링)
- **State & Storage**: React Hook Architecture + 브라우저 `localStorage` (진행도, 칭호 도감 영구 저장)

### 🖥️ 권장 실행 환경
- **디바이스**: PC(데스크톱, 노트북) 및 태블릿(가로 모드) 최적화
- **지원 브라우저**: Google Chrome, Microsoft Edge, Safari, Mozilla Firefox 최신 버전
- **최소 해상도**: 1024 × 768 이상 (가로 화면 권장)

## 7. 설치 및 실행 가이드

### 1) 사전 준비
- [Node.js](https://nodejs.org/) v18.18.0 이상 (v20 이상 LTS 권장)
- npm v9 이상

### 2) 저장소 복제 및 의존성 설치
```bash
# 프로젝트 디렉터리로 이동
cd c:\dev\history-pang-v1

# 의존성 패키지 설치
npm install
```

### 3) 로컬 개발 서버 실행
```bash
npm run dev
```
- 브라우저를 열고 `http://localhost:3000`에 접속합니다.

### 4) 프로덕션 최적화 빌드 및 실행
```bash
# 정적 페이지 및 번들 빌드
npm run build

# 프로덕션 서버 실행
npm start
```

   - 외부 데이터베이스나 외부 API 서버와의 실시간 통신 없이 100% 클라이언트 환경에서 독립적으로 완결 구동되므로, 네트워크 장애나 외부 서버 유출 위험 없이 교실 및 교육 환경에서 안전하게 운영할 수 있습니다.
2. **개인정보 보호**:
   - 학습자의 성명, 계정, 비밀번호 등 어떠한 개인 식별 정보도 수집하거나 외부로 전송하지 않습니다.
3. **진척도 저장**:
   - 진행 중인 시대 스테이지, 획득한 고유 유물, 12대 역사 도전 칭호 도감은 학습자의 로컬 브라우저 `localStorage`에 암호화/격리 저장되어 브라우저를 닫았다 다시 열어도 안전하게 이어할 수 있습니다.
